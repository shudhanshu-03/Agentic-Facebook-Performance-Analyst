# Agentic Facebook Performance Analyst  
A Multi-Agent System for Automated ROAS Diagnosis & Creative Recommendation

This repository contains a fully working **Agentic AI system** designed to autonomously analyze Facebook Ads performance, diagnose why Return on Ad Spend (ROAS) changes over time, and recommend improved creative messaging for low-CTR campaigns.

---

## 🚀 Project Overview

This system uses a **five-agent architecture**, where each agent plays a specialized role in the data analysis and creative generation pipeline:

1. **Planner Agent:** Breaks the user's high-level questions into structured, chronological subtasks for the other agents.
2. **Data Agent:** Processes and summarizes the raw Facebook Ads dataset (without passing the raw CSV directly to the LLM) to extract ROAS changes, CTR trends, spend/revenue patterns, and creative performance.
3. **Insight Agent (with Reflection):** Formulates hypotheses explaining ROAS fluctuations using structured reasoning. Features built-in retry logic to automatically reflect on and improve low-confidence hypotheses.
4. **Evaluator Agent (with Reflection):** Tests each hypothesis generated by the Insight Agent using quantitative statistics (e.g., period volatility, campaign rankings) and determines if they are Supported, Partially Supported, or Not Supported. Also features retry logic for low-confidence evaluations.
5. **Creative Agent:** Acts as the final step in the pipeline, generating new ad messages, concepts, and CTAs for low-performing campaigns, directly grounded in the high-CTR patterns identified by the Data Agent.

---

## 🧩 Core Features

- **Autonomous multi-agent orchestration**
- **LLM Agnostic:** Out-of-the-box support for the free **Groq API** (Llama-3.3-70b) as well as OpenAI.
- **Automated Reflection & Retry Logic:** The system autonomously critiques its own insights and evaluations, retrying generation if confidence scores fall below acceptable thresholds.
- **Data Summarization & Aggregation:** Safely aggregates sensitive CSV data into JSON contexts before passing it to language models.
- **Structured JSON Outputs:** Robust prompt engineering with enforced JSON-mode ensures predictable, parseable outputs. Generated inside `outputs/`.
  - `outputs/insights.json`  
  - `outputs/creatives.json`
  - `outputs/logs.txt` (detailed step-by-step thinking logs)

## ⚙️ Setup & Installation

1. **Clone the repository and enter the directory:**
   ```bash
   git clone <repository URL>
   cd "FB Agentic Analyst"
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure the Environment:**
   Rename `.env.example` to `.env`. It is configured to use the free **Groq API** by default. Simply insert your API key:
   ```env
   OPENAI_API_KEY="gsk_your_groq_api_key_here"
   OPENAI_BASE_URL="https://api.groq.com/openai/v1"
   LLM_MODEL="llama-3.3-70b-versatile"
   ```

4. **Run the Pipeline:**
   ```bash
   python run.py
   ```
   *Watch the console as the agents execute the pipeline. Check the `outputs/` folder for the final results.*
